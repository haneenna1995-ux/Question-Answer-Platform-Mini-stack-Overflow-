# Question & Answer Platform – Mini Stack Overflow

## Project Overview

This project is a full-stack web application inspired by Stack Overflow, designed to help users share IT knowledge by asking questions and providing answers.

Users can create an account, securely log in, and access a dashboard displaying questions posted by other users. Each question includes a title, description, and relevant tags to help users identify its topic.

Users can open individual questions to read more details and post answers. They can also create their own questions and assign tags to make the content easier to understand and discover.

The main goal of this project was to develop a functional and secure web application while gaining practical experience in backend development, frontend integration, database management, and deployment.

## Key Features

- **User Authentication:** Account registration and secure login with password hashing.
- **Question Dashboard:** View questions shared by users, including their associated tags.
- **Question Details:** Open questions to read their full descriptions and existing answers.
- **Post Questions:** Create questions with descriptions and relevant tags.
- **Post Answers:** Share knowledge by answering other users' questions.
- **Frontend–Backend Communication:** Connect the React frontend to Spring Boot REST APIs with a focus on secure communication.

## Development Experience

For the frontend, I worked with React and JavaScript to build a simple, user-friendly interface.

Testing

To improve the reliability and quality of the application, I applied different levels of software testing:

Unit Testing: Tested individual components and methods to verify that the application logic works as expected.

Integration Testing: Tested the interaction between different parts of the backend to ensure that components work correctly together.

End-to-End (E2E) Testing: Tested complete user workflows to verify that the application functions correctly from the user's perspective.

These tests helped me understand the importance of validating functionality at different levels and identifying issues during development.
